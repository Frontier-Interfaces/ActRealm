FAQ

A few useful answers before you write.

If these do not cover your situation, email us directly. A GitHub account is not required to contact support.

What can I contact ActRealm Support about?
You can contact us about installation, Provider setup, Runtime health, product behavior, bug reports, documentation, or other questions about using ActRealm.
Where should I start if ActRealm is not connecting?
Start with the current user guide and its Runtime and Provider checks. If the issue remains, email the result of the relevant redacted health check.
How should I report a suspected security issue?
Email hello@getactrealm.com privately. Do not open a public GitHub issue for suspected vulnerabilities, and do not include credentials, tokens, source files, or complete transcripts.
Do I need a GitHub account to get help?
No. GitHub is available for public documentation and reproducible issues, but you can always contact Frontier Interfaces Inc. directly at hello@getactrealm.com.
